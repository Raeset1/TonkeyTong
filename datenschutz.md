## Allgemeine Hinweise

Diese Datenschutzerklärung informiert darüber, welche personenbezogenen Daten beim Besuch dieser Website verarbeitet werden können.

Personenbezogene Daten sind alle Informationen, mit denen eine Person direkt oder indirekt identifiziert werden kann.

## Verantwortlicher

Die verantwortliche Stelle ist im [Impressum](/impressum/) aufgeführt.

## Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt.

Beim Aufruf der Website können technisch erforderliche Daten verarbeitet werden. Dazu können insbesondere gehören:

- IP-Adresse,
- Datum und Uhrzeit des Zugriffs,
- aufgerufene Seite oder Datei,
- übertragene Datenmenge,
- Browser und Betriebssystem,
- zuvor besuchte Seite,
- Informationen über den Erfolg des Seitenaufrufs.

Die Verarbeitung dieser Daten ist erforderlich, um die Website technisch bereitzustellen, die Sicherheit des Dienstes zu gewährleisten und mögliche technische Störungen zu untersuchen.

Weitere Informationen zur Datenverarbeitung durch GitHub können den Datenschutzhinweisen von GitHub entnommen werden.

## Google Search Console

Für diese Website wird die Google Search Console verwendet.

Die Google Search Console stellt Informationen darüber bereit, wie diese Website in der Google-Suche dargestellt und gefunden wird. Dazu gehören beispielsweise:

- Suchanfragen,
- Impressionen in der Google-Suche,
- Klicks aus Suchergebnissen,
- durchschnittliche Positionen,
- Informationen zur Indexierung der Website.

Durch die Verwendung der Google Search Console wird auf dieser Website kein eigenes Analyse- oder Tracking-Skript eingebunden.

## Cookies

Diese Website setzt derzeit keine eigenen Cookies ein.

Es werden insbesondere keine eigenen Cookies für Werbung, Benutzerprofile oder Besucheranalysen verwendet.

## Analyse und Tracking

Auf dieser Website werden derzeit keine zusätzlichen Besucheranalyse- oder Trackingdienste eingesetzt.

Es werden insbesondere nicht verwendet:

- Google Analytics,
- Werbenetzwerke,
- personalisierte Werbung,
- Social-Media-Tracking,
- eigene Benutzerprofile.

## Externe Links

Diese Website enthält Links zu externen Websites, beispielsweise zur offiziellen Microsoft-Dokumentation oder zu GitHub.

Beim Anklicken eines externen Links gelten die Datenschutzbestimmungen des jeweiligen Anbieters.

## Kontaktaufnahme

Wenn du per E-Mail Kontakt aufnimmst, werden die von dir übermittelten Informationen verarbeitet, um die Anfrage zu beantworten.

Die Daten werden nicht ohne deine Einwilligung für andere Zwecke verwendet.

## Rechte betroffener Personen

Im Rahmen der gesetzlichen Voraussetzungen bestehen insbesondere Rechte auf:

- Auskunft,
- Berichtigung,
- Löschung,
- Einschränkung der Verarbeitung,
- Widerspruch gegen die Verarbeitung,
- Datenübertragbarkeit.

Außerdem besteht das Recht, sich bei einer Datenschutzaufsichtsbehörde zu beschweren.

## Änderungen dieser Datenschutzerklärung

Diese Datenschutzerklärung kann angepasst werden, wenn neue Funktionen oder Dienste in die Website aufgenommen werden.
